# Agency Ops

Operational backbone for a hybrid marketing/creative agency and film/video production
house — creative briefs, production docs, proposals, content calendars, invoicing, and
status reporting, run through Claude Code role-based subagents and skills.

Start with [`CLAUDE.md`](./CLAUDE.md) for how the repo is organized, and
[`CONNECTORS.md`](./CONNECTORS.md) for which external tools to connect from the claude.ai
session UI.
